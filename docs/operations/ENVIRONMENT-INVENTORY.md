## How to read it

| Requirement | Meaning |
|---|---|
| **REQUIRED** | The platform cannot honestly onboard a paying tenant without it (launch-blocking), or a gate fails closed. |
| **DEGRADED** | Launch is possible; the capability lane runs in its honest absent/fallback mode without it. |
| **OPTIONAL** | A nice-to-have, an override, or a feature flag with a code default. |
| **PROVIDED** | Set by Vercel or Node; nothing to type in. |
| **DEV-ONLY** | Must be **unset in Production**; the code hard-gates it off there and the guard proves each gate. |
| **RETIRED** · **ALIAS** · **UNUSED** · **UNIMPLEMENTED** | Inert, a deprecated second spelling (set the survivor), declared but never obtained, or a lane that refuses honestly. |
| **CI/TOOLING** | Read by workflows, scripts or seed tooling, never by the deployed app. |

*Scope:* `server secret` is never sent to a browser; `public (browser bundle, build-time)` is inlined into the client bundle when the app is **built** (changing it needs a new build); `public by design` is a key that is safe to expose because every row it reaches is RLS-bound. *Tenancy* comes from `lib/providers/tenancy-matrix.ts`; a name with no row there is a platform-owned key. Tenant credentials (Twilio subaccounts, a tenant's Stripe or DocuSign account, OAuth tokens) are **never** environment variables — they are AES-256-GCM rows protected by `SECRETS_ENCRYPTION_KEY`.
