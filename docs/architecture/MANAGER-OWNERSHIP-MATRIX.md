## Blind spots

- A hop is the FIRST stripped-source line carrying its token; the guard proves the token is live code in that file, not that every path through the journey reaches it at run time — the named proofs carry the behaviour.
- Line anchors drift when a referenced file is edited; the structure (journeys, owners, domains, files, tokens) is compared exactly and drifted anchors are reported, so a stale line never turns the chain red on its own. Regenerate with `--write-doc`.
- Plays 1–5 are proven leg by leg by the proofs named in section 4 (SIMULATED, injected providers); only Play 6 is driven as one chained loop here.
